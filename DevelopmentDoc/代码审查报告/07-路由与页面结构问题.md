## 问题列表

### 1. proxy.ts 的命名和用途不清晰

**文件**: `src/app/proxy.ts`
**行号**: 1-107

**问题描述**:
文件名为 `proxy.ts` 但内容是路由保护逻辑，而非代理功能。

**当前代码**:
```typescript
/**
 * Next.js 16 Proxy 路由保护
 *
 * 替代已废弃的 middleware.ts 文件
 * 使用 proxy 文件约定实现路由级别的认证保护
 */
```

**问题分析**:
- `proxy.ts` 是 Next.js 16 的新约定，但对开发者来说不够直观
- 注释中提到是"proxy 文件约定"，但这是内部实现细节
- 文件名没有体现其用途（路由保护）

**修改建议**:
这是 Next.js 16 的约定，必须保留此文件名。但可以添加更清晰的文档。

**修改思路**:
```typescript
/**
 * Next.js 16 Proxy 文件 - 路由保护
 *
 * 这是 Next.js 16 的新约定文件，用于实现路由级别的保护逻辑。
 * 替代了以前需要在 middleware.ts 中实现的功能。
 *
 * 功能：
 * - 保护需要认证的路由（如 /dashboard）
 * - 防止已登录用户访问认证页面（如 /login）
 *
 * @see https://nextjs.org/docs/app/building-your-application/routing/colocation#route-protection
 */
```

### 2. Dashboard 布局中的硬编码 callbackUrl

**文件**: `src/app/(dashboard)/dashboard/layout.tsx`
**行号**: 21

**问题描述**:
与 `proxy.ts` 中的实现不一致，硬编码了 callbackUrl。

**当前代码**:
```typescript
// layout.tsx
redirect("/login?callbackUrl=/dashboard");

// proxy.ts 有更完善的实现
const callbackUrl = encodeURIComponent(pathname);
return {
    shouldRedirect: true,
    redirectTo: `/login?callbackUrl=${callbackUrl}`,
};
```

**问题分析**:
- 用户访问 `/dashboard/profile` 被重定向后，登录成功会跳转到 `/dashboard`
- 与 `proxy.ts` 的实现不一致

**修改建议**:
使用实际访问的路径

**修改思路**:
```typescript
export default async function DashboardLayout({ children }: DashboardLayoutProps) {
    const authenticated = await isAuthenticated();

    if (!authenticated) {
        // 使用 headers 获取当前路径（Next.js 16）
        const headersList = await headers();
        const pathname = headersList.get('x-pathname') || '/dashboard';
        const callbackUrl = encodeURIComponent(pathname);
        redirect(`/login?callbackUrl=${callbackUrl}`);
    }

    return <DashboardLayoutClient>{children}</DashboardLayoutClient>;
}
```

### 3. 路由组织结构不够清晰

**文件**: `src/app/` 目录结构
**行号**: N/A

**问题描述**:
路由组织结构可以进一步优化。

**当前结构**:
```
src/app/
├── (auth)/
│   ├── login/
│   └── register/
├── (dashboard)/dashboard/
│   ├── layout-editor/
│   ├── page-management/
│   ├── preview/
│   ├── profile/
│   ├── settings/
│   └── themes/
├── u/[username]/
└── api/
```

**问题分析**:
- `(dashboard)/dashboard/` 嵌套了重复的 `dashboard`
- 如果使用 `(dashboard)` 路由组，内部的 `dashboard` 文件夹是冗余的

**修改建议**:
简化路由结构

**修改思路**:
```
src/app/
├── (auth)/
│   ├── login/
│   └── register/
├── (dashboard)/              # 路由组
│   ├── layout.tsx           # 布局文件
│   ├── page.tsx             # /dashboard 首页
│   ├── layout-editor/       # /dashboard/layout-editor
│   ├── page-management/     # /dashboard/page-management
│   ├── preview/             # /dashboard/preview
│   ├── profile/             # /dashboard/profile
│   ├── settings/            # /dashboard/settings
│   └── themes/              # /dashboard/themes
├── u/[username]/
└── api/
```

### 4. 公开用户页面缺少 SEO 优化

**文件**: `src/app/u/[username]/page.tsx`
**行号**: N/A

**问题描述**:
公开用户页面可能缺少 SEO 优化元素。

**问题分析**:
- 缺少动态 metadata
- 缺少 Open Graph 标签
- 缺少结构化数据

**修改建议**:
添加 SEO 优化

**修改思路**:
```typescript
import { Metadata } from 'next';

// 动态生成 metadata
export async function generateMetadata({
  params,
}: {
  params: Promise<{ username: string }>;
}): Promise<Metadata> {
  const { username } = await params;
  const user = await getUserByUsername(username);

  if (!user) {
    return {
      title: '用户未找到',
    };
  }

  return {
    title: `${user.name || user.username} - LinkPro`,
    description: user.bio || `${user.name || user.username} 的个人主页`,
    openGraph: {
      title: `${user.name || user.username} - LinkPro`,
      description: user.bio || undefined,
      images: user.avatarUrl ? [{ url: user.avatarUrl }] : [],
      type: 'profile',
    },
    twitter: {
      card: 'summary',
      title: `${user.name || user.username} - LinkPro`,
      description: user.bio || undefined,
    },
    other: {
      'profile:username': username,
    },
  };
}
```

### 5. 缺少错误处理页面

**文件**: `src/app/`

**问题描述**:
缺少自定义的错误页面和加载状态。

**问题分析**:
- 没有全局 `error.tsx`
- 没有全局 `loading.tsx`
- 没有自定义 `not-found.tsx`（除用户页面外）

**修改建议**:
添加错误处理和加载状态

**修改思路**:
```typescript
// src/app/error.tsx
'use client';

import { useEffect } from 'react';
import { Button } from '@/components/ui/button';
import { Card } from '@/components/ui/card';

export default function Error({
  error,
  reset,
}: {
  error: Error & { digest?: string };
  reset: () => void;
}) {
  useEffect(() => {
    console.error('Application error:', error);
  }, [error]);

  return (
    <div className="flex min-h-screen items-center justify-center p-4">
      <Card className="max-w-md p-8 text-center">
        <h1 className="text-2xl font-bold">出错了</h1>
        <p className="mt-2 text-muted-foreground">
          应用程序遇到了一个错误
        </p>
        <Button onClick={reset} className="mt-4">
          重试
        </Button>
      </Card>
    </div>
  );
}

// src/app/loading.tsx
export default function Loading() {
  return (
    <div className="flex min-h-screen items-center justify-center">
      <div className="h-8 w-8 animate-spin rounded-full border-4 border-primary border-t-transparent" />
    </div>
  );
}
```

### 6. API 路由缺少版本控制

**文件**: `src/app/api/`

**问题描述**:
API 路由直接在 `api/` 下，没有版本控制。

**问题分析**:
- 未来修改 API 可能破坏现有客户端
- 没有 API 版本策略

**修改建议**:
添加 API 版本控制

**修改思路**:
```
src/app/api/
├── v1/
│   ├── auth/
│   │   └── [...nextauth]/
│   ├── links/
│   └── modules/
└── route.ts  # API 版本导航
```
