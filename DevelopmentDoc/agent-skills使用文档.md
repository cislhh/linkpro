## 概述

Agent Skills 是 Claude 的模块化扩展系统，每个技能都包含特定领域的专业知识、工作流程和工具。这些技能分为两大类：

1. **document-skills** - 文档处理技能
2. **example-skills** - 示例技能（涵盖创意、开发、企业等领域）

## 文档处理技能

### 1. docx - Word 文档处理

**技能描述：** 全面的 Word 文档创建、编辑和分析工具，支持修订追踪、评论、格式保留和文本提取。

#### 适用场景

| 场景 | 描述 |
|------|------|
| 创建新文档 | 从零开始创建专业的 Word 文档 |
| 编辑自己创建的文档 | 使用基础 OOXML 编辑进行简单修改 |
| 编辑他人文档 | 必须使用修订追踪工作流（推荐） |
| 法律/学术/商业文档 | 必须使用修订追踪工作流（必需） |
| 处理修订和评论 | 分析和处理文档中的追踪更改 |
| 文档格式分析 | 提取文本、分析文档结构 |

#### 核心功能

- **文档创建**：使用 docx-js 创建新 Word 文档
- **文档编辑**：使用 Python Document 库进行 OOXML 操作
- **修订追踪**：红线批注工作流，完整的追踪更改系统
- **文本提取**：使用 pandoc 转换为 markdown 格式
- **XML 访问**：解压文档访问原始 XML 结构

#### 关键工具

```bash
# 文本提取
pandoc --track-changes=all file.docx -o output.md

# 解压文档
python ooxml/scripts/unpack.py file.docx output_dir

# 打包文档
python ooxml/scripts/pack.py input_dir output.docx
```

#### 特色功能

- **红线条注工作流**：专业的文档修订流程，确保所有更改都被追踪
- **精确编辑原则**：只标记实际更改的文本，保持专业性
- **批量策略**：将相关更改分组（3-10个一批），便于调试

### 2. pdf - PDF 文档处理

**技能描述：** 全面的 PDF 操作工具包，支持文本和表格提取、创建新 PDF、合并/拆分文档以及表单处理。

#### 适用场景

| 场景 | 描述 |
|------|------|
| 填写 PDF 表单 | 填写和处理 PDF 表单字段 |
| 批量 PDF 处理 | 大规模 PDF 文档操作 |
| 文档合并 | 将多个 PDF 合并为一个 |
| 文档拆分 | 将 PDF 拆分为多个文件 |
| 文本提取 | 从 PDF 中提取文本内容 |
| 表格提取 | 从 PDF 中提取结构化表格数据 |
| OCR 处理 | 处理扫描版 PDF 文档 |

#### 核心功能

- **基础操作**：合并、拆分、旋转、加密 PDF
- **数据提取**：使用 pdfplumber 提取文本和表格
- **PDF 创建**：使用 reportlab 创建新 PDF
- **表单处理**：填写和提取 PDF 表单字段
- **OCR 支持**：处理扫描版 PDF

#### 关键工具

```python
# 读取 PDF
from pypdf import PdfReader, PdfWriter
reader = PdfReader("document.pdf")

# 提取文本
import pdfplumber
with pdfplumber.open("document.pdf") as pdf:
    text = pdf.pages[0].extract_text()

# 提取表格
tables = pdf.pages[0].extract_tables()
```

#### 特色功能

- **表单处理**：专门的 forms.md 指南处理 PDF 表单
- **表格提取到 Excel**：使用 pandas 将表格导出为 XLSX
- **批量操作**：支持命令行工具进行快速处理

### 4. xlsx - Excel 电子表格处理

**技能描述：** 全面的电子表格创建、编辑和分析工具，支持公式、格式化、数据分析和可视化。

#### 适用场景

| 场景 | 描述 |
|------|------|
| 创建财务模型 | 创建专业的财务模型和分析 |
| 数据分析 | 使用 pandas 进行数据分析 |
| 编辑现有表格 | 保留公式和格式进行编辑 |
| 数据可视化 | 在 Excel 中创建图表 |
| 公式重新计算 | 使用 LibreOffice 重新计算公式 |

#### 核心功能

- **使用 openpyxl**：处理公式和格式化
- **使用 pandas**：进行数据分析和操作
- **公式验证**：使用 recalc.py 验证公式正确性
- **金融模型标准**：行业标准颜色编码和格式

#### 关键工具

```python
# 使用 openpyxl
from openpyxl import Workbook, load_workbook
wb = Workbook()
sheet = wb.active
sheet['A1'] = '=SUM(B2:B9)'

# 使用 pandas
import pandas as pd
df = pd.read_excel('file.xlsx')
df.to_excel('output.xlsx', index=False)
```

#### 金融模型颜色标准

| 颜色 | 用途 | RGB 值 |
|------|------|--------|
| 蓝色文本 | 硬编码输入 | (0, 0, 255) |
| 黑色文本 | 所有公式和计算 | (0, 0, 0) |
| 绿色文本 | 工作表内部链接 | (0, 128, 0) |
| 红色文本 | 外部文件链接 | (255, 0, 0) |
| 黄色背景 | 需要关注的关键假设 | (255, 255, 0) |

#### 核心原则

- **使用公式而非硬编码**：所有计算应使用 Excel 公式
- **零公式错误**：交付的模型必须无 #REF!、#DIV/0! 等错误
- **保留模板格式**：修改现有文件时匹配其格式

### 13. webapp-testing - Web 应用测试

**技能描述：** 使用 Playwright 与本地 Web 应用交互和测试的工具包。

#### 适用场景

| 场景 | 描述 |
|------|------|
| 前端验证 | 验证前端功能 |
| UI 调试 | 调试 UI 行为 |
| 截图捕获 | 捕获浏览器截图 |
| 浏览器日志 | 查看浏览器日志 |

#### 决策树

```
用户任务 → 是静态 HTML？
    ├─ 是 → 直接读取 HTML 识别选择器
    │         ├─ 成功 → 编写 Playwright 脚本
    │         └─ 失败 → 视为动态
    │
    └─ 否（动态 Web 应用）→ 服务器已运行？
        ├─ 否 → 使用 with_server.py
        │
        └─ 是 → 侦察然后行动：
            1. 导航并等待 networkidle
            2. 截图或检查 DOM
            3. 识别选择器
            4. 执行操作
```

#### 关键工具

```bash
# 单服务器
python scripts/with_server.py --server "npm run dev" --port 5173 -- python automation.py

# 多服务器
python scripts/with_server.py \
  --server "cd backend && python server.py" --port 3000 \
  --server "cd frontend && npm run dev" --port 5173 \
  -- python automation.py
```

#### 最佳实践

- 使用 `sync_playwright()` 编写同步脚本
- 始终关闭浏览器
- 等待 `networkidle` 再检查动态应用
- 使用描述性选择器
